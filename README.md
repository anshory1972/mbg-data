# MBG data: Susenas September 2025 (beta)

Tables on the Free Nutritious Meals programme (Makan Bergizi Gratis, MBG) from the
September 2025 National Socio-Economic Survey (Susenas) of Statistics Indonesia (BPS).

Web page: https://anshory1972.github.io/mbg-data/

This is a beta version. The numbers and the page may still change.

| Folder | Content |
|---|---|
| `index.html`, `data.json` | The web page and the table data it shows |
| `files/` | All tables as CSV, and the questionnaire pages (BPS, VSEN25.M) |
| `code/` | The Stata code that produces every number, with a README |

Only tables are published. Susenas microdata are licensed by BPS and are not in
this repository. Cells with fewer than 30 respondents are not shown.

Source: BPS, Survei Sosial Ekonomi Nasional (Susenas) September 2025. Tables
computed by SDGs Center, Universitas Padjadjaran.
